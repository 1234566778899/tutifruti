# Tutifruti AI · Web

Versión web (SvelteKit + Svelte 5) de Tutifruti AI: https://tutifruti.site

Juega en las mismas salas que la app de iPhone (mismas RPC de Supabase).

```bash
npm install
npm run dev      # http://localhost:5173
npm run check    # tipos
npm run build
```

Se despliega automáticamente en Vercel con cada push a `main`.
